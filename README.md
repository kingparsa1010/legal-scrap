# سامانه پایش و استخراج علائم تجاری (Legal-Scrap)
**Trademark Monitoring & Brand Similarity Protection System (SSAA / مرکز مالکیت معنوی)**

یک نرم‌افزار دسکتاپ ویندوزی مستقل با رابط کاربری فارسی (RTL) جهت استخراج خودکار اظهارنامه‌های ثبت علامت تجاری از پایگاه مرکز مالکیت معنوی کشور (`ipm.ssaa.ir`)، تفکیک هوشمند موارد رد شده، و ارزیابی شباهت برند جهت حفاظت از علائم تجاری شرکت (مانند **«متاسنت Metacent»** و محصولات دارویی/دامی در طبقه ۵).

---

## ویژگی‌های کلیدی سامانه

1. **نمایش مستقیم کد امنیتی (کپچا) در نرم‌افزار:**
   - نیازی به باز بودن مرورگر کروم نیست.
   - تصویر کپچا مستقیماً در پنجره برنامه لود می‌شود؛ کاربر ۴ رقم را وارد کرده و جستجو آغاز می‌شود.
2. **پوشش تمامی فیلدهای جستجوی سامانه:**
   - تاریخ انتشار (از / تا) و تاریخ اظهارنامه (از / تا)
   - طبقه‌بندی کالا و خدمات (پیش‌فرض طبقه ۵)
   - شماره اظهارنامه، شماره ثبت، و شماره بین‌المللی
   - نوع تطابق عنوان (عین عبارت، شروع شود با، شامل و مشابه)
   - نوع شخص (حقیقی / حقوقی)، نام و کد ملی مالک، شماره ثبت و شناسه ملی شرکت
3. **موتور شباهت‌سنجی هوشمند (فازی و آوایی):**
   - نرمال‌سازی حروف فارسی و عربی (`ی`، `ک`، حذف اعراب و تنوین).
   - تطابق آوایی (حروف هم‌صدا مانند ث/س/ص، ت/ط، ز/ذ/ض/ظ، غ/ق).
   - تطابق لاتین و آوایی انگلیسی (مانند `Metasent` در برابر `Metacent`).
   - طبقه‌بندی ریسک: **خطر بالا (High Risk بالای ۸۰٪)** و **خطر متوسط (Medium Risk بین ۶۵٪ تا ۸۰٪)**.
4. **تفکیک خودکار موارد «رد شده»:**
   - رکوردهایی که وضعیت آن‌ها «رد شده» است به عنوان هشدار فعال ثبت نمی‌شوند تا لیست هشدارهای فوری قانونی مخدوش نگردد.
5. **پایگاه داده محلی SQLite و ذخیره بر اساس تاریخ:**
   - کلیه اسکن‌ها با تاریخ و پارامترها ذخیره می‌شوند.
   - امکان بازخوانی آنی رکوردهای هر تاریخ با یک کلیک در تب تاریخچه (Openability).
## ساختار ۳ تب اختصاصی نرم‌افزار

نرم‌افزار دقیقاً دارای **۳ تب** اختصاصی است:
1. **تب ۱: Matching, Active Brandings**
   - نمایش پرونده‌های در جریان و فعال (غیر رد شده) که دارای شباهت اسمی/آوایی با برند مرجع هستند.
   - همراه با درصد شباهت، رده ریسک (خطر بالا / خطر متوسط) و دکمه باز کردن مستقیم پرونده.
2. **تب ۲: Rejected**
   - تفکیک اختصاصی کلیه پرونده‌هایی که وضعیت آن‌ها در سامانه ثبت «رد شده» است، جهت عدم اختلاط با هشدارهای فعال.
3. **تب ۳: ALL SCRAPED RECORDS**
   - نمایش تمامی اظهارنامه‌های استخراج‌شده در اسکن جاری بدون هیچ‌گونه فیلتر.

*نکته: منوی کشویی تاریخچه جستجوهای قبلی مستقیماً در نوار بالای بخش نتایج قرار دارد و فیلترهای گذشته را با یک کلیک بازیابی می‌کند.*

## ساختار پروژه

```
legal-scrap/
├── gui/
│   ├── __init__.py
│   └── app.py            # رابط کاربری دسکتاپ PyQt6 فارسی با تب‌های تفکیک‌شده
├── scanner/
│   ├── __init__.py
│   ├── client.py         # کلاینت مستقیم HTTP و مدیریت نشست سامانه ثبت
│   ├── parser.py         # تجزیه‌گر HTML و استخراج فیلدهای هر اظهارنامه
│   ├── similarity.py     # موتور شباهت‌سنجی فازی و آوایی فارسی/انگلیسی
│   ├── database.py       # مدیریت پایگاه داده محلی SQLite (scans.db)
│   ├── exporter.py       # تولیدکننده گزارش‌های دوره‌ای اکسل
│   └── worker.py         # نخ پردازشی پس‌زمینه (QThread)
├── tests/
│   ├── __init__.py
│   └── test_components.py # تست‌های خودکار واحد
├── reports/              # پوشه ذخیره خودکار فایل‌های اکسل
├── main.py               # نقطه ورود و اجرای برنامه
└── requirements.txt      # پیش‌نیازهای پایتون
```

## نحوه اجرا

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. اجرای نرم‌افزار
```bash
python main.py
```

### ۳. اجرای تست‌های واحد
```bash
python tests/test_components.py
```

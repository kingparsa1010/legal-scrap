# سامانه پایش و استخراج علائم تجاری (Legal-Scrap)
**Trademark Monitoring & Brand Similarity Protection System (SSAA / مرکز مالکیت معنوی)**

یک نرم‌افزار دسکتاپ ویندوزی مستقل با رابط کاربری فارسی (RTL) جهت استخراج خودکار اظهارنامه‌های ثبت علامت تجاری از پایگاه مرکز مالکیت معنوی کشور (`ipm.ssaa.ir`)، تفکیک هوشمند موارد رد شده، و ارزیابی شباهت برند جهت حفاظت از علائم تجاری شرکت (مانند **«متاسنت Metacent»** و محصولات دارویی/دامی در طبقه ۵).

---

## ویژگی‌های کلیدی سامانه

1. **نمایش مستقیم کد امنیتی (کپچا) در نرم‌افزار:**
   - نیازی به باز بودن مرورگر کروم نیست.
   - تصویر کپچا مستقیماً در پنجره برنامه لود می‌شود؛ کاربر ۴ رقم را وارد کرده و جستجو آغاز می‌شود.
2. **پوشش تمامی فیلدهای جستجوی سامانه:**
   - تاریخ انتشار (از / تا) و تاریخ اظهارنامه (از / تا)
   - طبقه‌بندی کالا و خدمات (پیش‌فرض طبقه ۵)
   - شماره اظهارنامه، شماره ثبت، و شماره بین‌المللی
   - نوع تطابق عنوان (عین عبارت، شروع شود با، شامل و مشابه)
   - نوع شخص (حقیقی / حقوقی)، نام و کد ملی مالک، شماره ثبت و شناسه ملی شرکت
3. **موتور شباهت‌سنجی هوشمند (فازی و آوایی):**
   - نرمال‌سازی حروف فارسی و عربی (`ی`، `ک`، حذف اعراب و تنوین).
   - تطابق آوایی (حروف هم‌صدا مانند ث/س/ص، ت/ط، ز/ذ/ض/ظ، غ/ق).
   - تطابق لاتین و آوایی انگلیسی (مانند `Metasent` در برابر `Metacent`).
   - طبقه‌بندی ریسک: **خطر بالا (High Risk ۸۵٪ و بالاتر)** و **خطر متوسط (Medium Risk بین ۷۰٪ تا ۸۵٪)**.
4. **تفکیک خودکار موارد «رد شده»:**
   - رکوردهایی که وضعیت آن‌ها «رد شده» است به عنوان هشدار فعال ثبت نمی‌شوند تا لیست هشدارهای فوری قانونی مخدوش نگردد.
5. **پایگاه داده محلی SQLite و ذخیره بر اساس تاریخ:**
   - کلیه اسکن‌ها با تاریخ و پارامترها ذخیره می‌شوند.
   - امکان بازخوانی آنی رکوردهای هر تاریخ با یک کلیک در تب تاریخچه (Openability).
## ساختار دو حالت و تب‌های نتایج

نرم‌افزار دو حالت کاملاً مستقل دارد؛ هر حالت پنل نتایج، جدول‌ها و شمارنده‌های خود را دارد و جابه‌جایی بین حالت‌ها داده‌ها را پاک نمی‌کند:

### حالت ۱ — پایش لیست عمومی (DeclarationList)
1. **ALL SCRAPED RECORDS** — کلیه اظهارنامه‌های استخراج‌شده بدون فیلتر.
2. **ACTIVE ONLY** — فقط پرونده‌های با وضعیت «ثبت قطعی شده» (مبنای واحد: `is_finally_registered`).

### حالت ۲ — جستجوی هدفمند (طبقه ۵)
1. **CAPTURED CLASS 5** — رکوردهای استخراج‌شده از جستجوی فیلتردار طبقه ۵.
2. **MATCHED** — نتیجه مقایسه دستی عنوان‌های کاربر با رکوردهای طبقه ۵ در پایگاه داده SQLite (شباهت ۷۰٪ به بالا؛ دکمه «🔄 مقایسه با data_store»).

**مقایسه فقط دستی است** (بدون اجرای خودکار هنگام تعویض حالت). مخزن داده SQLite (`scans.db`) بین اجراها و حالت‌ها پایدار می‌ماند و هر دو بخش اظهارنامه‌های کاربر و رکوردهای عمومی طبقه ۵ را به صورت یکپارچه نگهداری می‌کند.

**حالت‌های اسکن لیست اظهارنامه‌ها:**
- **جستجوی موارد جدید (سریع):** استخراج رکوردهای جدید تا رسیدن به رکوردهای تکراری قبلی و ادغام در مخزن.
- **اسکن کامل (Full Rescan):** اسکن کلیه صفحات سامانه و بازنویسی و جایگزینی کامل (Override & Overwrite) اطلاعات در مخزن.

*نکته: منوی کشویی تاریخچه جستجوهای قبلی (فقط حالت ۲) در نوار بالای بخش نتایج قرار دارد.*

## ساختار پروژه

```
legal-scrap/
├── gui/
│   ├── __init__.py
│   └── app.py            # رابط کاربری دسکتاپ PyQt6 فارسی با تب‌های تفکیک‌شده
├── scanner/
│   ├── __init__.py
│   ├── client.py          # کلاینت مستقیم HTTP و مدیریت نشست سامانه ثبت
│   ├── parser.py          # تجزیه‌گر HTML + وضعیت‌های واحد (is_finally_registered / is_rejected_status)
│   ├── similarity.py      # موتور شباهت‌سنجی فازی و آوایی فارسی/انگلیسی
│   ├── comparator.py      # مقایسه دستی عناوین کاربر با رکوردهای طبقه ۵
│   ├── store.py           # لایه سازگاری مخزن SQLite (شامل declarations و class5)
│   ├── database.py        # مدیریت پایگاه داده محلی SQLite (scans.db)
│   ├── exporter.py        # گزارش اکسل متناسب با حالت فعال
│   ├── declaration_worker.py  # نخ حالت ۱ (لیست عمومی)
│   └── worker.py          # نخ حالت ۲ (جستجوی هدفمند)
├── services/              # منطق کاربردی مستقل از Qt (اسکن، اعتبارسنجی و ثبت نهایی)
├── validation/            # قالب داده برچسب‌خورده و ابزار سنجش precision/recall
├── tests/
│   └── test_*.py          # تست‌های ذخیره‌سازی، اسکن و شباهت
├── reports/              # پوشه ذخیره خودکار فایل‌های اکسل
├── main.py               # نقطه ورود و اجرای برنامه
└── requirements.txt      # پیش‌نیازهای پایتون
```

## نحوه اجرا

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. اجرای نرم‌افزار
```bash
python main.py
```

### ۳. اجرای تست‌های واحد
```bash
python -m unittest discover -s tests -v
```

## اعتبارسنجی موتور شباهت

فایل `validation/labeled_examples.csv` عمداً خالی است تا نمونه ساختگی به عنوان
حقیقت حقوقی استفاده نشود. پس از افزودن جفت‌های بررسی‌شده توسط کارشناس:

```bash
python validation/validate_similarity.py validation/labeled_examples.csv
```

این ابزار precision و recall آستانه‌های مختلف را گزارش می‌کند و تنظیمات عملیاتی
را به‌صورت خودکار تغییر نمی‌دهد.
